# The gate ledger

One row per standing rule in `CLAUDE.md`, keyed on the rule's bold lead-in, verbatim: the class
the rule names, the gate that holds it, and what the gate reads or why no reader can exist.
`tests/python/contracts/test_gate_ledger.py` holds every rule to a row, every row to a rule, every
gate to a test that exists, and every `prose` row to a reason. It was written at v1.39.0 as the
first milestone of `docs/ROADMAP_2_0.md`; the roadmap's v1.41 is the rows below whose gates are
instance tests of a rule that names a class.

How to read a row. **Class** is what the rule applies to - every payload field, every write of
the purse, every leaf - or `—` when the rule is a practice for the person writing a gate. **Gate**
is one or more test ids, `;`-separated, in the collector's own spelling (`tests/....py::Class::test`)
or a Go test's (`go_core/..._test.go::TestName`); or the word `prose`. **Drill** says what the gate
walks and what shape fails it - *class* when it walks every site so a new one cannot escape,
*instance* when it exercises named functions or cases - or, on a prose row, why nothing can read
the rule.

A gate named here is a reader, not a claim: a name appearing in a test is not the test holding
the rule (v1.0.0-rc.58), which is why each row says what is walked. When a rule is added to
`CLAUDE.md`, its row is added here in the same change; when a gate is renamed, the test above
names the row that points at nothing.

## Gates and drills

| Rule | Class | Gate | Drill |
|---|---|---|---|
| **Drill every gate.** | — | prose | A practice for the person writing a gate: revert the fix and read the failure. Six gates carry their own drill against planted input (`TestThePlaceFloorGateSeesWhatItForbids`, `TestTheWorldExitGateSeesALocationInsideASetList`, the dead-buy-line reader, the whereabouts reader, the hint detector, the checklist-name pattern), and `docs/FINDINGS.md` records each release's drills; no test can tell whether a gate was drilled when it was written. |
| **Read code by AST, not by searching text (rc.52).** | — | prose | A practice for the person writing a gate.
